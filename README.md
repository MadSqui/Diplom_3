## Автоматизированное тестирование веб-приложения Stellar Burgers

#### Включает автоматизированные тесты для проверки функциональности веб-приложения Stellar Burgers с использованием:

* Паттерна Page Object Model (POM) для структурирования тестового кода.

* Кроссбраузерного тестирования (Google Chrome и Mozilla Firefox).

* Allure-отчетов для наглядного представления результатов.

# Что протестировано:
### 1. Восстановление пароля
* Переход на страницу восстановления пароля.

* Ввод почты и восстановление пароля.

* Работа кнопки "Показать/скрыть пароль".

### 2. Личный кабинет
* Переход в личный кабинет.

* Проверка раздела "История заказов".

* Выход из аккаунта.

### 3. Основной функционал
* Работа конструктора бургеров.

* Отображение деталей ингредиента.

* Оформление заказа авторизованным пользователем.

### 4. Лента заказов
* Открытие деталей заказа.

* Синхронизация истории заказов с лентой.

* Обновление счетчиков заказов (всего/сегодня).

* Отображение заказов "В работе".

## Техническая реализация:
Язык и фреймворки: Python 3, pytest, Selenium WebDriver.

Паттерн: Page Object Model (отдельные классы для страниц).

Драйверы: ChromeDriver и GeckoDriver (для Firefox).

Отчеты: Allure Framework с детализацией шагов.

Данные: Конфигурация через urls.py и data.py.


Установка зависимостей:
pip install -r requirements.txt

Запустите тестов:
pytest tests--alluredir=allure-results

Генерирование Allure-отчета:
allure serve allure-results
